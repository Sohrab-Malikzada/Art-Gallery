# Art Gallery & Painting Management System

## Project Overview

**Art Gallery & Painting Management System** is a full-stack web application developed to provide a digital platform for showcasing, managing, and interacting with artwork. The system combines a public art gallery interface with an administrative content-management workflow, allowing paintings and their information to be managed dynamically through a PHP/MySQL backend.

The project was built from scratch using **PHP, MySQL, JavaScript, Bootstrap, HTML5, and CSS3**, with a focus on practical full-stack web development, database integration, dynamic content rendering, and user-friendly interface design.

* Artist name
* Creation year
* Artwork dimensions

This approach allows the gallery content to be managed through the application instead of hard-coding individual paintings directly into the frontend.

## Architecture

The application follows a practical client-server architecture:

**User Interface**
↓
**HTML / CSS / Bootstrap / JavaScript**
↓
**PHP Backend**
↓
**MySQL Database**

User interactions are handled through the frontend, while PHP processes application logic and communicates with MySQL to store and retrieve dynamic artwork data.

## Development Highlights

Instead of displaying fixed artwork information directly inside HTML, the system uses PHP and MySQL to manage and retrieve painting data dynamically. This provides a more scalable structure for adding and maintaining a larger collection of artworks.
